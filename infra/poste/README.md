# Installation d'un poste

Cible : installeur Windows signé (Tauri 2), configuration à l'installation (nom du poste, secret,
adresse du hub, certificat interne), base SQLite chiffrée, mises à jour servies par le hub.

À produire en P2/P4 : script d'installation, liste des prérequis (WebView2, imprimante 80 mm),
procédure de ré-hydratation d'un poste réinstallé.
