# Vecteurs de tests

Cas JSON (entrée → sortie) **exportés de la maquette** (`PR.repartir`, `PR.encaisser`, `SIGH.emettreAvoir`,
`SIGH.exercice`, `SIGH.bfr`…) et rejoués par `dart test` **et** par le banc Node. Une règle sans vecteur
n'est pas portée. Générés par un script de `prototype_html/build/` (à écrire : phase P1 du plan).
